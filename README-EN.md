# budongsan-tax

mcp-name: io.github.taylee9809/budongsan-tax

![demo](docs/demo.gif)

Korean real-estate tax engine. Runs as an MCP server.
Covers acquisition tax, property tax, comprehensive real-estate holding tax, capital gains tax, residential rental income tax,
gift and inheritance tax on real estate, and the reconstruction excess-profit levy.

Every result carries the statute articles applied, the articles considered but not applied with the reason, and a provenance grade for each input.
Official rulings from the National Tax Service, the Tax Tribunal and the Ministry of the Interior are the answer key for regression tests.

This is not tax advice. A result is one reading of the statute. File and appeal with a licensed tax accountant or lawyer.
No warranty (AGPL §15, §16). [한국어 README](README.md).

```bash
uvx budongsan-tax            # from PyPI, no clone
```

Claude Code:

```bash
claude mcp add budongsan-tax -- uvx budongsan-tax
```

Claude Desktop `claude_desktop_config.json`:

```json
{"mcpServers": {"budongsan-tax": {"command": "uvx", "args": ["budongsan-tax"]}}}
```

From source: `pip install -r requirements.txt && python tax_server.py`. The statute and ruling lookup tools need `LAW_OC`
(a free key from open.law.go.kr) in `.env`; the calculators do not.

## Tools

The prefix tells the role. `judge_*` settles facts: household, home count, exemption and relief eligibility. Call these first.
`calc_*` takes those facts and returns amounts. `count_*` counts homes. `search_*` and `get_*` look up statutes, ordinances
and rulings and need `LAW_OC`. The full list with one-line descriptions is in [`llms.txt`](llms.txt).

## Layout

| layer | where | what |
|---|---|---|
| 1 values | `data/tax_params.json`, `tax_params.py` | rate tables, ratios, caps, by year. Unverified years are refused |
| 2 statute text | `data/legal_nodes/` | article text and effective dates; the "grounds" field of a result points here |
| 3 judges and calculators | `tax_judgment.py`, `tax_server.py`, `entity_tax.py` | the 43 tools. Older structure: several articles per function |
| 4 statute nodes | `tax_nodes/` | one article per function; a computation is a composition of nodes; replacing layer 3 |
| verification | `data/verification/`, `tax_case_store.py` | cases, defects, rulings |

Per-article conversion status: [`docs/NODE_COVERAGE.md`](docs/NODE_COVERAGE.md).
