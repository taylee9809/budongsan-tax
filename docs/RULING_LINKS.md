# 판례 ↔ 실행 노드 연결

`scripts/link_rulings.py`가 생성한다. 판례·심판례·예규가 인용한 조문을 현행 조문 제목과 대조해 실행 노드에 붙인다. 손으로 고치지 않는다.

| 항목 | 값 |
|---|---:|
| 판례 전체 | 1318 |
| 인용 조문이 1개 이상인 판례 | 1020 |
| 실행 노드에 연결된 판례 | 772 |
| 판례가 붙은 조문(현행) | 200 |
